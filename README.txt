MOKA — static Shoptet bundle demo
=================================

This is a completely static demo. No Python, server, database or build step is needed.

OPEN LOCALLY
------------
Double-click index.html, or open it in a browser.

GITHUB PAGES
------------
1. Create a GitHub repository.
2. Upload index.html, styles.css and script.js to the repository root.
3. In the repository go to Settings -> Pages.
4. Set source to Deploy from a branch, select main / root, and save.
5. GitHub will give you a public URL you can send to businesses.

WHAT WORKS
----------
- Main quantity selector and simulated Add to cart.
- Interactive 4-item bundle selector.
- Bundle progress and validation.
- Simulated Add bundle to cart.
- Related-product quick-add buttons.
- Product information tabs.
- Responsive layout.
- Any normal shop link/search opens a clear "this is only a demo" message rather than leaving the page.

All store names, products, prices and contact details are fictional and intended only for demonstration.
